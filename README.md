# Doutor Resolve Tech

Sistema de gestão para serviços, vendas e produção.

## Primeira entrega
- Interface inicial responsiva.
- Dashboard demonstrativo.
- Navegação entre módulos.
- Prévia de PDV, ordens de serviço, produção gráfica, clientes, relatórios e configurações.

## Tecnologias
- React + TypeScript
- Vite
- Lucide React
- Netlify (publicação)

## Desenvolvimento
Esta versão é somente o front-end demonstrativo. Os dados exibidos são fictícios e ainda não existe conexão com Supabase.

## Publicação no Netlify
- Build command: `npm run build`
- Publish directory: `dist`

Próxima etapa: conectar autenticação e banco de dados Supabase.
